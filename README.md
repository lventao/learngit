## 📖 简介

本仓库是学习[廖雪峰 Git 教程](https://liaoxuefeng.com/books/git/)的实战练习记录，覆盖**2020 年 1 月 至 2024 年 9 月**，按月度组织提交。

涵盖 Git 核心概念：版本回退、分支管理、标签操作、远程协作、Pull Request 等。

## 🎯 学习路线

| 阶段 | 内容 | 关键命令 |
|:---|:---|:---|
| 🔰 入门 | 仓库初始化、暂存、提交、版本回退 | `init` `add` `commit` `reset` `log` |
| 🌿 分支 | 分支创建/切换/合并、冲突解决 | `branch` `checkout` `merge` `stash` |
| ☁️ 远程 | 克隆、推送、拉取、远程管理 | `clone` `push` `pull` `remote` `fetch` |
| 🏷️ 标签 | 版本标记、标签管理 | `tag` `show` |
| 🔧 进阶 | 变基、拣选、子模块、自定义 Git | `rebase` `cherry-pick` `submodule` |
